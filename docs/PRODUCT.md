# 产品说明

## 产品定位

学者画像系统面向高校科研管理、课题组负责人和学术分析人员。用户输入姓名并选择明确的 OpenAlex 实体后，系统生成论文统计、研究方向、代表论文、合作网络和证据化总结。

## 当前功能

1. **检索与消歧**：中文名补充两种拼音顺序，只按 OpenAlex ID 去重。候选展示机构、ORCID、论文数、引用数和 h-index。
2. **完整画像**：分页获取作者详情与全部论文，计算引用指标、研究方向、兴趣演化和合作关系。
3. **全量论文**：画像 JSON 保持轻量，论文列表从 PostgreSQL 游标分页读取。
4. **稳定合作图**：节点以 OpenAlex ID 为主键；同名合作者显示机构或短 ID；图谱高度随浏览器视口调整。
5. **质量保护**：分页不完整、数量明显不一致、论文异常下降或工作流报错时不发布新版。
6. **当前数据**：每次用户查询画像都重新获取 OpenAlex 当前数据；最近成功画像仅用于质量对比和更新保护。
7. **自动更新**：收藏学者每天检查，近 30 天访问学者每 7 天检查；任务最多重试 3 次。
8. **登录与私有数据**：用户可自助注册本地账号并自动登录；查询、画像、论文、SSE、历史和收藏均只对登录用户开放。
9. **实时换版**：数据库发布版本变化后，前端通过 SSE 自动加载最新版。
10. **流式进度**：每次画像查询持续展示节点、百分比和阶段消息，异常通过 NDJSON error 事件结束等待。
11. **一致跳转**：从候选列表、合作节点、查询历史或收藏查看画像时，搜索框同步显示当前学者姓名。
12. **响应式界面**：文章详情、查询历史和收藏在桌面端占用独立栏并压缩主内容，窄屏端使用可滚动抽屉；导航、搜索和长文本不产生横向溢出。

## 数据与隐私边界

- 首版只使用 OpenAlex，但保留 `source/source_id` 以便二期接入 ORCID 或其他来源。
- 不自动合并多个 OpenAlex 作者 ID；`quality_flags` 只提示同名、机构冲突或主题跨度风险。
- 旧 SQLite 13 条缓存不迁移，自托管 PostgreSQL 从空库开始。
- 只保留最新成功画像和 30 天任务日志，不保存历史画像版本。
- 密码使用带随机盐的 scrypt 摘要保存，数据库不保存明文密码。
- 浏览器仅持有高熵、`HttpOnly` 的不透明会话 Cookie；数据库只保存会话 token 的 SHA-256 摘要。
- 登录失败按用户名和 IP 限速；错误响应不区分用户不存在、密码错误或账号停用。
- 注册不依赖邮箱、短信或微信；同一来源 IP 每小时最多尝试注册 10 次，密码重置暂由服务器管理员处理。

## 成功标准

- 匿名用户只能访问前端登录页、健康检查和会话检查；所有平台查询能力必须登录。
- 不同用户的查询历史和收藏按 `user_id` 隔离。
- 学者超过 50 篇论文时仍可分页访问全部论文。
- 每次交互式画像查询都重新获取 OpenAlex 当前数据，不直接返回已有画像。
- 部分 OpenAlex 结果不能覆盖旧画像；完整成功更新才递增版本。
- SSE 收到新版本后自动切换最新版。
- Web、worker、PostgreSQL 和前端可由 Docker Compose 启动，也可拆分部署到 ECS/RDS。
- Gitee 拉取后只需填写 `.env` 并运行受保护的部署脚本，无需修改应用源码。
- 生产环境允许公开注册和登录，但没有开发登录后门；无有效会话的查询请求统一返回 401。
- 已检查的 Ubuntu 24.04 阿里云 ECS 可由引导脚本自动安装 Docker、补充 Swap、生成随机数据库密码和完成首次部署。

## 上线前事项

- 单机 ECS 首次启动会创建 PostgreSQL 17、数据库所有者和受限的 `scholar_app` 账号；使用 RDS 时需单独准备对应角色。
- 配置正式域名、HTTPS、CORS 和安全 Cookie。
- 将 Web 与 worker 作为独立进程运行，配置日志、监控、重启策略和告警。
- 配置自动备份到独立介质，并完成至少一次恢复演练。
- 禁止公网访问数据库和后端内部端口；所有真实密钥由部署环境注入。
